# vps master guide

**A VPS (Virtual Private Server) is a virtual machine hosted by a cloud provider. You get dedicated resources such as CPU, RAM, storage, and an operating system to host websites, applications, databases, APIs, automation tools, and other services.**

**You can host your website on a VPS (Virtual Private Server) by connecting your domain name to your VPS public IP address, installing a web server such as Nginx or Apache, and configuring SSL for HTTPS.**

## What else can you host on a VPS?

| Technology | Use case |
|----|----|
| HTML, CSS, JavaScript |	Static website |
| React |	Frontend application |
| Node.js / Express |	Backend API |
| Python / Django	| Python web application | 
| Flask / FastAPI	| Python REST API |
| MongoDB |	Database |
| MySQL |	Database |
| n8n |	Workflow automation |
| Docker | Containerized applications |
